# Lumiterra V2 产品理解分析

- 日期：2026-08-26
- 阶段：Early Prototype
- 依据：`memory/current.md`、`sources/requirements.md`、`sources/numeric-core.md`
- 用途：内部运营理解；不代表最终公开口径

## 核心结论

Lumiterra V2 当前定义为运行在 Monad 上、由 Agent 主导的 Fully Onchain 养成放置类游戏。宠物与 Agent 不是两套角色：宠物是人类手动入口，Agent 是购买后的自动控制入口，两者在同一套位置、战棋、生产、成长与经济规则中行动。

运营上应把产品理解为三个相连的支柱：可配置并受预算约束的 Agent 行动；战斗、采集、种田共用战棋底层并共同成长；Energy、固定财富值和资产流转构成有成本、有损耗、有约束的经济。固定财富值、财富转化率与奖池权重均不等于 Token 收益。

## 已确认产品事实

### 产品与控制入口

- 所有账户默认没有 Agent。玩家可先创建仅影响外观的宠物，并领取绑定的 Lv1 剑、斧头、水壶。
- 创建宠物与领取初始装备不收游戏内费用或 Energy；手动链上操作的 Gas 由玩家钱包支付，协议不补贴。
- Agent 可自动执行移动、战斗、采集、种田、合成和经济行为。玩家可管理其 Prompt、Context、Behavior Codes、性格、启停、预算和资产。
- 五项 `0–100` 性格参数只影响决策权重和 Prompt，不改变链上数值。
- 无 Agent 时宠物使用待校准的最低属性。有 Agent 时，宠物逐项取最低属性与账户最强 Agent 属性 33% 中较高者；移动范围取 5 与来源 Agent 移动范围中较高者；背包始终为 2。

### 统一战棋与掉落

- 战斗、采集、种田共用地图、阵营回合、移动、技能、伤害、多人加入和掉落结算，只替换对象、职业属性、武器、表现与掉落表。
- 三种行为分别要求剑、斧头、水壶。怪物可移动；采集物和作物默认不移动，但可在敌方回合攻击。
- 协议随机决定先手；友方与敌方回合各最多 60 秒，整场遭遇最多 30 分钟。
- 同阵营对象可并发决策，按协议实际确认顺序执行。其他宠物或 Agent 可动态加入；同账户多个对象仍各自计算行动、伤害和掉落。
- 每一件物品按目标的有效伤害占比独立随机分配；稀有掉落只允许伤害占比不低于 5% 的对象参与。
- Agent 死亡、撤离或背包不足时，已抽中的物品留在遭遇地点待领取；宠物容量不足时物品直接消失且不重抽。
- 敌方死亡后即时结算；遭遇超时后，已死亡对象的掉落保留，存活对象不掉落。已发生的 Gas、模型调用和运行 Energy 不退还。

### 成长与装备

- 每个 Agent 只有一条 Lv1–9 成长进度，不拆职业等级。每阶段需 2,000 件合格有效成长掉落，八次升级合计 16,000 件；超额不结转。
- 合格掉落必须实际分给该 Agent、完成激活、属于基础掉落，且物品等级等于当前阶段。宠物、交易、转入、合成、赠送、稀有和额外奖励均不计入。
- 720 小时是典型装备与正常路线下从 Lv1 到 Lv9 的目标有效生产时间；每日 12 小时对应 60 天只是推算，不是最短时间或结果保证。
- 成长阶段只决定基础 HP、移动范围和背包容量。Lv1–Lv9 为 `1×–5×`、`5–13` 格、`10–1,000`。
- 任意成长阶段可穿戴任意等级装备。装备提供对应职业的攻击、防御和暴击，不增加 HP；三种行为的有效生产等级分别只读取剑、斧头、水壶等级。

### Energy、产出与价值

- 只有逐件分配后实际归属并完成激活的产出才扣生产 Energy、结算固定财富值；空产出和未激活物品不结算。
- 无 Agent 时不开放 Energy 充值，宠物产出默认未激活。购买 Agent 后可付 Energy 激活历史物品并获得固定财富值，但不补发成长进度。
- Agent 使用不可透支的预付运行 Energy 池，余额不足时在下一收费点或安全行动边界暂停。
- 当前规则为 `1 Energy = 1 MON`，Energy 由官方统一销售且不可在 Marketplace 交易。
- 同级单件 Energy 基准从 Lv1 的 `1` 增至 Lv9 的 `16`；财富转化率从 `70%` 增至 `95%`。这是内部成本/价值公式，不是收益率。
- 基础物品固定财富值由物品等级决定；实际 Energy 成本还读取装备决定的有效生产等级。每小时产量需结合地图、技能、移动、人数、刷新和掉落模拟，不能仅由公式承诺。

### 合成与经济模块

- 同职业同等级三种不同基础素材各 1 件合成 1 份精华；本职业装备消耗另外两职业同等级精华，Lv2 以上另销毁上一等级同槽位装备。
- 当前规则为固定配方、100% 成功率，合成本身不额外耗 Energy；产物继承全部销毁输入的固定财富值。
- 奖池投入不可撤回，按投入物固定财富值确定当期 Token 分配权重。
- 回收只读取固定财富值。Slow Redeem 的 7 天/5% 与 Fast Redeem 的 10% 是初始模拟值，Fast Redeem 还受动态额度限制。
- 单件装备可担保一笔 P2P 贷款；托管期间可使用，但不能交易、转移、回收、投池或再抵押。
- 主城仓库容量无限并由同账户宠物与全部 Agent 共享。物品不能跨地点直接用于生产、合成或穿戴；Marketplace 买入后也需到场 Claim。

## 运营判断（非产品承诺）

1. **Agent 应表达为“可配置的行动者”**：它的价值在于按目标、上下文、性格和预算持续决策执行，而不是解锁另一套游戏。传播应展示配置如何改变真实行动，不能只展示聊天界面。
2. **三职业应表达为共同生产网络**：统一战棋、合并成长和跨职业配方使三种玩法彼此连接，而不是三个孤立小游戏。
3. **“无需先买 Agent”不等于“零成本”**：玩家可先进入并体验基础行为，但仍需钱包 Gas，产出默认未激活且宠物背包仅为 2。
4. **经济传播先讲规则与选择**：适合强调预算、装备、库存、位置和风险管理；不得将固定财富值、回本测试、回收或奖池翻译成 APY、保本或稳定收益。
5. **Fully Onchain 需要证据**：文档定义了协议随机、链上确认顺序、原子结算和位置校验，但本地资料没有实际部署范围。公开传播前需说明哪些状态、决策、执行和结算可验证。

## 对外表达边界

### 相对安全

- 产品运行在 Monad 上，当前处于 Early Prototype。
- 玩家可手动控制宠物，或购买并配置 Agent 自动行动。
- 三种玩法共用统一战棋底层，共同推进一条 Agent 成长进度，并通过跨职业合成互相依赖。
- Agent 支持 Prompt、Context、Behavior Codes、性格和预算配置。

### 必须加限定

- `720 小时`、`60 天`仅为典型条件下平衡目标/示例。
- `1 Energy = 1 MON`、`70%–95%`及等级曲线是 Early Prototype 当前规则，不是收益或不变承诺。
- `7 天、5%、10%`是回收初始模拟参数。
- 宠物 `33%`继承需逐属性与最低值取高，移动范围另算。
- 自动运行仍受 Energy、Gas、位置、背包、HP 和世界规则限制。
- Token 奖池只能说明权重机制，不能承诺规模、数量、价格或回报。

### 不得承诺

- 上线、测试、Agent 售卖或 Token 日期；
- Agent 价格、供应量、可转移性、稀缺性或投资价值；
- 固定收益、回本、APY、Token 价格或经济结果；
- 所有经济模块同时首发，或现有数值永不调整；
- 零 Gas、零成本、完全被动收入；
- 未经技术证据确认的完整链上范围。

## 建议内部表达

> Lumiterra V2 是运行在 Monad 上、由 Agent 主导的 Fully Onchain 养成放置类游戏；玩家既可手动控制宠物，也可配置 Agent，让它在统一战棋、成长和经济约束下持续行动。

三个叙事支柱：可配置的 Agent 行动；统一成长的生产世界；有成本、有约束且不承诺收益的链上经济。
