# 视觉创作图片引用工作流

日期：2026-09-02

## 本次完成

- 将“素材工作室”更名为“视觉创作”，子页面调整为“创作 / 素材库 / 我的作品”。
- 新增独立“修改图片”入口，先单选唯一修改对象，再描述修改要求。
- 补充要求与版本调整输入支持输入 `@` 搜索并引用具体图片。
- 为上传素材和生成图片补充稳定编号：上传素材使用 `REF-*`，生成图片使用 `IMG-*`。
- 图片选择器、参考条、作品卡片、当前结果和详情统一显示编号与名称。
- 详情支持重命名和复制 `@编号`；重命名不改变稳定编号或作品版本链。
- 新作品使用随机稳定分组 ID，避免同名作品被错误归到同一个版本组。
- OpenAI 图片修改请求明确标注主图和普通参考图片的顺序与角色。

## 重要判断

- “修改对象”与“参考图片”必须是两个不同概念：前者只有一个，后者可以有多个。
- 用户识别图片依赖可读名称，系统精确引用依赖稳定编号；两者需要同时显示。
- 同名不代表同一作品，因此作品分组不能继续使用名称作为身份。
