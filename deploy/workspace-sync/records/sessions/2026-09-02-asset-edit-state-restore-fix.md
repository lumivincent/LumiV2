# 素材编辑状态恢复修复

## 完成内容

- 将素材工作室的本地状态恢复从“组件挂载时执行一次”改为“素材页第一次真正显示时执行”。
- 保存并恢复图片制作、参考素材、生成作品三个子页面的位置。
- 保存并恢复当前调整输入与“基于已采用图片继续迭代”的编辑状态。
- 空标题、空要求和清空全部参考图片现在也能按真实状态恢复，不会被默认值覆盖。

## 根因

- 素材工作室为了保留运行任务会一直挂载并在其他页面隐藏；此前恢复逻辑在非素材页面挂载时直接退出，之后切回素材页也不会再次执行。
- “继续迭代”只存在于组件内存，没有进入本地工作状态；页面重新加载后，已采用图片会重新显示为完成态，看起来像当前创作被自动归档。

## 验证

- ESLint 通过。
- Next.js 生产构建通过；保留既有动态文件追踪警告，不影响构建完成。
- 本地网页实测：在素材页填写临时作品名称和画面目标，切换到内容页、刷新、再返回素材页，两项内容均成功恢复。
- 验证后已通过“取消本次制作”清理临时测试输入，未生成、采用或修改任何素材文件。

## 边界

- 本次仅修复浏览器中的工作状态恢复，不改变生成作品的草稿/已采用元数据，也没有新增自动归档行为。
