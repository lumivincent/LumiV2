# 内容与图片多轮创作会话

## 完成内容

- 内容结果区增加创作会话、最近轮次与继续修改输入
- 素材结果区增加创作会话、最近轮次与继续生成输入
- Codex 内容开始保存并续接线程；Codex 图片继续沿用现有线程
- OpenAI API 内容保存 Response ID，并在下一轮使用 previous_response_id
- OpenAI API 图片保留首轮直接生成，后续修改使用 Responses API 图像生成工具建立多轮编辑会话
- 内容和素材记录保存最近八轮调整与前序要求摘要
- 切换 Codex / API 或达到八轮时，从当前版本和摘要重新建立执行会话

## 重要判断

- 创作会话是单条内容或单组作品的短期工作记忆，不是新的长期项目记忆
- 执行方式切换时共享当前版本、参考素材和明确要求，不假设两种执行方式能够共享内部隐藏上下文
- 草稿和未采用图片不会因为进入创作会话而自动成为官方表达或视觉标准

## 验证

- Lint 通过
- Production build 通过
- 本地首页、内容 API 和图片 API 配置检查正常
- 未执行付费内容或图片生成
