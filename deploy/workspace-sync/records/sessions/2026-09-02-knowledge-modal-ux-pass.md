# 知识与分析弹窗体验优化

- 时间：2026-09-02
- 类型：运营工作台 UI 优化

## 完成内容

- 缩小桌面弹窗尺寸，把空白会话的说明和输入框集中到视觉中心。
- 修复发送按钮文字不可见的问题，并统一发送、保存分析和加入知识库的主按钮状态。
- 弹窗打开时锁定背景页面滚动，关闭后恢复，避免内外双滚动条。
- 压缩直接添加表单，新增独立原始链接输入；桌面端无需滚动即可完成主要录入。
- “归入主题”只显示主题，选择器在靠近底部时向上展开，避免被弹窗裁切。
- 直接添加状态下隐藏“新对话”，标题改为“添加知识文档”。
- 未发送的问题和未保存的知识文档在当前浏览器会话中自动恢复；清空新对话前增加确认。

## 验证

- 已验证知识讨论、直接添加、向上展开的主题选择器、草稿关闭重开恢复、分析空状态、按钮颜色和背景滚动恢复。
