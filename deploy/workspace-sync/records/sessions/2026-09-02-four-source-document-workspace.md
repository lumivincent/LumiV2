## 完成内容

- 将文档来源扩展为需求文档、数值文档、Agent 交互和抽奖交互四类。
- 更新动作改为先完整下载四类源文件，再统一保存；任一下载失败时不进行部分更新。
- 原样保存两类 Markdown 与两类交互 JavaScript，并使用哈希、更新时间和历史快照追踪版本。

- 每一类都有独立的“分析此分类”入口；Codex 与 OpenAI API 都只注入当前分类源文件，并在会话和分析记录中保存分类范围。
