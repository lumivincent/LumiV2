+ ### 7.1 Energy 路由与国库记账
+ - MON 按 `1 MON = 1 Energy` 充值；Energy 不可交易，不能直接兑换为 OHM 或质押权重。
+ - 用于游戏行为、Agent 运行和装备成长的 Energy 是纯游戏消耗，不进入 OHM mint 额度。
+ - 只有抽奖消耗的 Energy 被视为 Bond 购买资产；对应 MON 从充值储备账本全额划入 Bond 国库账本。游戏成长 Energy 对应的 MON 不进入该账本。
+ - 每笔 Bond 单独计算 `LotteryBondProfit = LotteryEnergySpent - BondOHMPayout`。该利润只生成未铸造的 OHM 待分配额度；实际 OHM 在抽奖 payout 或 Agent 挖掘结算时才铸造。
+ ### 7.2 抽奖式 Bond
+ - 一次抽奖严格对应一次 Bond 购买：投入 `X` Energy，按 Bond 定价获得随机数量 `Q` OHM。
+ - `Q` 当场铸造并计入总供应，先锁入 depository；只有已解锁 OHM 才能卖出或注入 Agent。
+ - `Q` 的数学期望必须等于同笔确定性 Bond 的 payout，随机只在玩家之间重分配结果，不改变长期总发放量。
+ - Bond 使用 Token/MON 的 4 小时 TWAP、1 MON 固定地板和随时间衰减的需求计数器定价；详细曲线见数值文档。
+ - 抽奖档位、概率、数量和地板钳位必须经过期望配平，不允许因最大 payout 钳位而暗中降低 Bond 期望。
+ ### 7.3 Agent Stake 与 30 分钟 epoch
+ - 只有已解锁 OHM 可注入 Agent。注入量是该 Agent 的 Stake 本金，也是分配 OHM 额度的唯一直接权重。
+ - 每个 mining epoch 固定为 30 分钟。本 epoch 发生的注入、自动复投或退出请求于下一个 epoch 边界生效，因此本 epoch 内的分配权重和可挖额度保持固定。
+ - Bond 利润进入全局待分配池，使用 8 小时半衰期的指数平滑曲线，每 30 分钟只释放待分配池的一部分。
+ - 每个 Agent 按其生效 Stake 占全局生效 Stake 的比例获得新额度。当前 epoch 未挖完额度结转到下一 epoch。
+ - Agent 发起退出时，对应 Stake 从下一个 epoch 起停止获得 OHM 额度和退出罚金分配；未挖额度按退出比例退回全局待分配池，剩余部分继续绑定在该 Agent。
+ - 若全局生效 Stake 为 0，本 epoch 不释放 OHM，全部利润额度继续留在待分配池。
+ ### 7.4 Shadow 式线性退出
+ - 玩家可以选择立即退出，或选择 `7–30 天`的线性退出期；退出期最终按 30 分钟 epoch 对齐。
+ - 立即退出扣除退出本金的 `50%`；线性退出在 7 天时同样为 `50%`，此后随等待时间线性下降，30 天时为 `0%`。
+ - 退出请求一经确认不可取消。净到账 OHM 进入退出托管，到期后转为钱包可用余额；退出队列中的 OHM 不再获得 epoch 额度、素材挖掘权或退出罚金分配。
+ - 退出罚金不进入协议收入，也不生成新 OHM。罚金按结算快照中仍处于有效 Stake、且未进入退出队列的 OHM 比例分配。
+ - 玩家获得的罚金份额直接增加对应 Agent 的注入量，从下一个 epoch 生效，不能先进入可提现余额，并继续受同一退出规则约束。
+ - 为防止看到大额退出后临时注入抢罚金，只有在罚金结算快照前已经连续生效至少 `7 天`的 Stake 才有资格参与该笔罚金分配；不满足资格的份额由其余合格 Stake 按比例承接。若没有合格 Stake，该笔已经铸造的罚金 OHM 留在独立的 `ExitPenaltyCarryPool`，等出现合格 Stake 后再分配，不能混入未铸造的 Bond 利润池，也不能被退出者或结算调用者领取。
+ ### 7.5 素材挖 OHM 与自动复投
+ - Agent 在 epoch 开始时锁定 `AgentQuotaAtEpochStart = 历史未挖额度 + 本 epoch 新增额度`。
+ - 每件当场完成 Energy 激活的基础素材，按素材等级对应的指数曲线兑现 `AgentQuotaAtEpochStart` 的一定比例。
+ - Lv1 素材每件兑现 `1%`，Lv9 素材每件兑现 `9%`；中间等级使用底数 `1.25` 的归一化指数曲线。
+ - 同一 epoch 的每件素材始终以 `AgentQuotaAtEpochStart` 为基数，不以剩余额度连续复利；累计挖掘不得超过当前剩余额度。
+ - Agent 等级通过移动格数、行动速度和可产出的素材等级影响挖掘速度；装备通过职业数值影响实际生产速度。二者都不直接改变 Stake 分配权重。
+ - 实际挖出的 OHM 自动复投到同一 Agent，下一个 epoch 生效。
+ ### 7.6 单件装备 P2P 借贷
+ - 成交后装备进入托管；借款人可以继续使用，但不能交易、转移或再次抵押。
+ - 协议只对实际支付或已收取的利息收费。
