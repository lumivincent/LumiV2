# Olympus DAO / OHM：机制、增长与崩盘快速理解

第一次了解 OHM 先读这里：用一份完整脉络理解它的机制、冷启动、Marketing、FOMO 来源与崩盘原因。

## 阅读路径

- 想快速掌握我们目前怎么看：看[核心结论](../insights/2026-09-01-ohm-core-conclusions.md)。
- 想核对数据和原始说法：打开[源头资料](../sources/2026-09-01-ohm-source-library.md)。

## 一句话看懂

Olympus 用国库、协议自有流动性、债券和高额 rebase 奖励组成增长系统，再用 `(3,3)`、社区活动与合作网络把复杂机制变成可传播的身份和故事。它在 2021 年制造了极强的增长与 FOMO，也因为新增发行、市场溢价和持续新需求高度互相依赖，在需求转弱后形成反向飞轮。

## OHM 到底是什么

Olympus 希望创建一种不锚定美元、但由协议国库资产支持的自由浮动货币 OHM。

- **Treasury**：持有 DAI、FRAX、LP 等资产，为协议发行和运营提供储备。
- **Bonding**：用户把 DAI、FRAX 或 LP token 交给协议，换取折价、分期释放的 OHM；协议因此获得资产和自己的流动性。
- **Protocol-Owned Liquidity（POL）**：协议不再持续发币“租”流动性，而是逐步拥有交易池 LP。这是 Olympus 最真实、影响最持久的创新。
- **Staking / Rebase**：用户质押 OHM 获得 sOHM，余额约每 8 小时增加一次。前端把短期发行率年化为极高 APY。
- **Treasury-backed, not pegged**：OHM 不等于 1 美元稳定币，国库支持也不代表用户能按市场价或 backing 随时赎回。

[V1 发行公式](https://github.com/OlympusDAO/olympus-docs/blob/main/docs/contracts-old/equations.md)显示，新增 OHM 同时分配给 staker、bonder、DAO 与 pOHM 行权方，供应没有硬上限。因此“币的数量增加”不自动等于“购买力增加”。

## 增长系统如何运转

上涨阶段的核心循环是：

`新用户买入 → OHM 高于国库支持价值 → 债券折扣有吸引力 → 协议获得更多资产和流动性 → Dashboard 数据继续增长 → 高 APY、社区和媒体吸引更多用户`

这个循环同时把三类东西组合在一起：

1. **金融钩子**：高 APY、每 8 小时余额增长、债券折扣。
2. **可信故事**：国库、POL、runway、链上 Dashboard、DeFi reserve currency。
3. **传播系统**：`(3,3)`、Ohmie、FOHMO、教育内容、Meme、合作协议和 DeFi 2.0。

单看其中任何一项都不足以解释 2021 年 9–11 月的爆发；真正的 FOMO 来自它们同步增强。

## 冷启动做对了什么

### 发行本身就是第一轮获客

Initial Discord Offering 把“进入 Discord”变成参加发行的资格。按比例而不是先到先得，降低机器人和抢跑焦虑；“反巨鲸、社区所有”的解释又给早期成员一个愿意主动转述的理由。

这里能确认的是发行规则和早期社群增长。没有公开渠道归因数据证明后续增长由 Discord 资格制单独造成，因此它应被理解为一套有效的**所有权与身份设计**，不是可复制的增长公式。

### 产品每天自动制造内容

下一次 rebase、不断增加的 sOHM 余额、APY、国库、backing 和 runway，让用户每天都有理由回来，也能随手截图传播。产品界面本身成为内容生产器。

### 用一句话压缩复杂机制

`(3,3)` 同时承担四件事：解释共同质押、告诉用户该做什么、识别同类、强化群体规范。用户无需复述完整白皮书就能加入传播。

它的反面是把卖出或质疑隐含为“不合作”。而且 sOHM 可以解除质押或用于借贷，高质押率不等于硬锁仓。

### 把活动做成社区仪式

FOHMO 不只是 AMA：它组合了新人介绍、产品更新、行业嘉宾、游戏、音乐、NFT、Giveaway、贡献者招募和 afterparty。Agora、Sherpa / OLY 101、社区 DD 与 Meme 又承接了活动之外的持续教育。

### 把合作变成分发网络

Olympus Pro 为其他协议提供 bonding 服务。每次伙伴接入都会产生产品使用、双方公告、教育内容和伙伴社群触达。后期材料显示它服务过 50+ 协议、7 条链、近 1.5 亿美元资产。

但合作必须准确理解：Aave 社区要求 exposure cap 与独立风控，Maker 对 OHM 抵押品接入以 53.76% 反对。进入头部协议讨论证明影响力和关注度，不等于技术或风险背书。

## FOMO 为什么会爆发

OHM 的 FOMO 可拆成六个同时出现的信号：

1. **数字冲击**：五位数 APY、每 8 小时余额增长。
2. **稀缺与复利想象**：早期资格、高质押率、“越晚进入越少复利”。
3. **风险缓释故事**：Treasury、backing、POL、runway 与链上 Dashboard。
4. **群体身份**：`(3,3)`、Ohmie、FOHMO、Meme 和“我们一起赢”。
5. **外部注意力**：Bankless、DeFi 创始人、伙伴协议、DeFi 2.0 和大量 forks。
6. **可见增长**：持有人、国库、伙伴、活动、市值同时上升，用户感知中每个数字都在为其他数字作证。

这是解释爆发的框架，不是统计归因模型。公开资料没有给出各渠道转化率、留存率或 CAC。

## 哪些是真创新，哪些是误导性理解

### 可以确认的价值

- POL 解决了流动性挖矿昂贵、流动性随激励离开的真实问题。
- Bonding 能让协议用自己的 token 购买储备和 LP。
- Olympus 把复杂 tokenomics 转译成了极强的产品反馈、内容、身份与社区参与系统。
- Olympus Pro 证明 bonding 能被产品化并服务其他协议。

### 容易被误解的部分

- **高 APY ≠ 外部现金收益**：主要是新增 OHM 发行的年化表达。
- **余额增加 ≠ 财富等比例增加**：供应也在增长，价格可能下跌得更快。
- **backing ≠ 赎回权**：国库账面资产不保证高于 backing 的市场价格。
- **高质押率 ≠ 不会卖**：质押可解除，也可能进入借贷和杠杆。
- **伙伴接入 ≠ 风险背书**：行业关注、产品合作和资产认可需要分开。

## 为什么后来崩盘

反转不是某次营销失误，也不是单一巨鲸导致，而是原有增长循环反向运行：

`新增需求下降 → OHM 溢价收缩 → 债券需求和协议收入下降 → 供应仍扩张 → 单位价格与 backing per OHM 承压 → 用户退出 → 杠杆清算 → 更大卖压`

证据链包括：

- V1 代码确认新增发行与无硬上限；
- [OIP-43](https://forum.olympusdao.finance/d/325-oip-43-launch-cvx-bonds)直接承认协议高度依赖 bond demand；
- [OIP-63](https://forum.olympusdao.finance/d/755-oip-63-reward-rate-adjustment)指出供应增长必须与协议增长匹配；
- 2022 年 1 月 17 日链上交易确认约 82,526.7 OHM 换得 11,368,224 DAI；
- The Block、CoinDesk 与 Decrypt 同期记录了卖出、质押率下降和 Fuse 清算。

POL 仍然有价值，但它不能保护 OHM 的高市场溢价；强社区能改善留存，但不能取消退出和风险管理；高 APY 能加速增长，也会在需求转弱时加速稀释压力。

## 对 Lumiterra V2 最重要的启发

以下是运营判断，不是已确认的 Lumiterra 产品方案：

- 借鉴“把第一批用户变成有身份、有任务、有可见贡献的创世成员”，不要照搬金融 APY。
- 产品应持续产生用户能感受、理解和展示的真实进展，但指标必须对应真实价值。
- 需要短而统一的协作语言，但不把退出、质疑或风险管理污名化。
- 社区活动可以同时承担教育、仪式、内容素材和贡献者招募。
- 合作应产生真实产品价值、共同用户行为和可验证结果，不做纯 Logo 墙。
- 如果发行机制参考 OHM，必须讲清奖励来源、供应变化、价值支撑、退出路径与最坏状态。

## 当前仍不知道什么

- Discord、FOHMO、Bankless、Olympus Pro 各自带来多少新增用户；
- 各渠道的真实转化率、留存率与 CAC；
- 2021 年完整 Twitter / Discord 历史曝光数据；
- staking TVL 中净新增资金、OHM 价格与 rebase 供应各自贡献多少。
