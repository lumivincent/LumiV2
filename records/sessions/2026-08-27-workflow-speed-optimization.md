# 工作流与生成速度优化

- 记录时间：2026-08-27

## 完成内容

- 内容创作和图片制作的未完成状态自动保存在本机，刷新后恢复
- 图片首张继续保留完整任务与执行记录；有 Codex 会话的后续版本直接恢复会话，跳过重复任务文件、产品文档读取和执行记录
- Codex 执行拆分为文字与图片两条通道，允许两类任务同时运行，同类任务仍保持单任务执行
- 参考素材支持设置为默认参考，新建独立制作和内容配图时自动带入
- 连续创作显示最近使用项目，可直接载入最新作品、视觉规则和会话
- 前端将“继续系列”改为“连续创作”，移除倒计时、MEME 等示例型固定类别，改为通用用途分类

## 边界

- 没有增加项目管理、排期、审批或复杂素材标签系统
- 内容与素材仍然是独立工作项，只在用户选择时关联
- 本地自动恢复用于当前设备的工作现场，正式内容和生成作品仍保存到工作区

## 验证

- ESLint 通过
- Next.js 生产构建通过
- 本地页面返回正常
