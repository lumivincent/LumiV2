# 素材工作室重构

- 记录时间：2026-08-27

## 完成内容

- 将素材模块重构为“图片制作 / 参考素材 / 生成作品”三个视图
- 将 Codex ImageGen 设为默认生成方式，OpenAI API 放入备用入口
- 支持上传参考素材、分类、选取参考、作品状态、版本分组和详情查看
- 将 Brief 与执行记录从素材网格移入生成作品详情
- 将已有 Fully Onchain Poster 登记为 Codex ImageGen 生成作品 V1
- Codex 执行结果现在会识别新生成的 PNG、JPG 与 WebP 文件

## 关键判断

- 文档分析、内容创作与素材制作继续保持独立工作项，只共享项目记忆
- 上传参考与生成作品必须在界面与数据层同时区分
- 不把 API Key 配置作为默认生成流程的前置条件
