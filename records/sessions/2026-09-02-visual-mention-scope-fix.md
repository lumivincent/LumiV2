# 图片引用候选范围修复

日期：2026-09-02

## 问题

画面目标输入 `@` 时会列出整个素材库和历史生成图片，不符合“先选择参考，再在 Prompt 中指定参考图作用”的流程。

## 修复

- `@图片` 候选只读取本次“参考资料”中已经选择的图片。
- 未选择任何参考图时，提示先通过“添加图片”选择。
- 已选图片仍会随生成请求发送；`@编号` 用于在 Prompt 中说明各图片的具体作用。

## 验证

- 生产构建与 TypeScript 校验通过。
- 页面当前选择 `REF-004` 与 `REF-002` 两张参考图；在画面目标输入 `@` 后，候选列表只返回这两个编号。
