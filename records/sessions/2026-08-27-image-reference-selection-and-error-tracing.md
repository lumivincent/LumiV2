# 图片参考多选与失败追踪

## 本次完成

- 检查“概念版海报”使用的提示词、输出规格和 3 张默认参考素材。
- 确认提示词无明显安全或格式问题，参考素材均为受支持的 PNG、JPG 或 WebP，文件大小正常。
- 确认 OpenAI `gpt-image-2` 支持多张输入图片，当前 `image[]` 请求格式与官方示例一致。
- 移除图片制作前端、本机草稿恢复、默认参考、首轮 Image API 和多轮 Responses API 中的人为 4 张截断。
- 参考选择器改为不限数量多选，并显示当前已选数量；批量上传的图片全部加入本次参考。
- 在当前结果区增加明确的生成中状态。
- API 失败后保留错误说明、稳定错误码与 OpenAI 请求编号；错误刷新后仍可查看，服务端同时记录不含密钥的诊断信息。

## 判断

- 之前的失败不是由“只能使用 4 张参考图”导致，当时只有 3 张。
- 旧版本没有保留 API 错误码与请求编号，且当前任务没有连接到当时的服务端终端，因此无法还原那一次请求的精确失败原因。
- OpenAI 官方说明复杂图片可能需要约 2 分钟；旧界面在等待阶段右侧保持空白，容易被误判为没有执行。

## 验证

- ESLint 通过。
- Next.js 生产构建通过。
- 本地首页与图片接口均返回 200，图片接口确认已配置 `gpt-image-2`。
