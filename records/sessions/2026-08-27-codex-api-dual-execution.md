# Codex / OpenAI API 双执行方式

## 完成内容

- 内容创作增加 Codex / OpenAI API 执行方式切换，结果进入同一内容记录
- 素材工作室增加 Codex ImageGen / OpenAI API 执行方式切换，结果进入同一作品版本链
- 内容 API 使用当前产品事实、项目记忆、相关定稿内容、当前草稿和本次背景组成精简上下文
- 保存内容生成方式、模型和 API Token 用量
- 切换图片执行方式时保留参考素材、连续创作规则、内容关联与已有 Codex 会话线索
- 增加 OpenAI 文本模型环境变量示例，默认使用 gpt-5.6-terra；图片继续使用 gpt-image-2

## 重要判断

- Codex 与 API 是执行方式，不是两套内容库或两套记忆
- 长期记忆仍只接收定稿和已发布内容，草稿不进入表达标准
- API 不持续累加完整聊天历史，改为按任务筛选上下文，控制无用信息与 Token 消耗
