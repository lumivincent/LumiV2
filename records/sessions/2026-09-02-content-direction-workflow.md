# 内容创作方向选择与精修工作流改造

## 本次完成

- 首轮创作改为默认生成三个真正不同的创意方向，每个方向包含名称、判断角度和完整正文。
- 三个方向先在页面内比较，只有用户选中后才保存为正文版本；未选择的方向不会覆盖当前稿件。
- 已选创意方向随内容记录保存，后续多轮修改默认围绕该方向进行。
- 快捷操作重新分为定向精修、语气调整、转换与延伸、定稿前检查。
- 强化开头、压缩及语气按钮增加保留边界，避免一次局部要求导致整篇换方向。
- 事实检查不再直接重写正文，先展示结论、风险、产品依据和修正版，由用户决定是否载入。
- 从历史版本继续修改时停止续接最新版本的隐藏 Response/Thread，创建新的上下文分支。
- Codex 内容精修改为轻量对话执行，不再为每次新分支创建额外任务文件。
- OpenAI API 创作上下文缩减为更相关的产品片段、项目记忆和知识参考，降低短推文的信息噪音。
- 未选择的三方向结果保存在浏览器工作状态中；刷新页面不会立即丢失。
- 当本地编辑内容与已保存文件不一致时，页面明确显示“本地未保存”。

## 重要判断

- 三个方向只用于首次探索或主动换方向；选定后每轮只返回一个新版，避免比较成本反复出现。
- Crypto Native、自然、神秘和冲突感属于语气调整，不再与核心创意方向混为一类。
- 事实检查与文案创作分开，避免检查动作静默改变用户认可的表达。
- 最新 `sources/` 仍是产品事实来源，知识库和历史内容不能覆盖当前产品事实。

## 验证

- OpenAI API 配置接口仍返回 `gpt-5.6-sol`。
- 实际调用 `gpt-5.6-sol` 成功返回 A/B/C 三个结构完整的方向；本次验证输入 3,771 Tokens、输出 417 Tokens，未写入内容记录。
- ESLint 通过。
- Next.js 生产构建通过；保留既有 Turbopack 动态文件追踪警告，本次未新增构建错误。
- 本地网页实际加载无控制台错误；在窄屏下快捷操作由原来的大面积纵向排列收敛为两列、约 127px 高。
