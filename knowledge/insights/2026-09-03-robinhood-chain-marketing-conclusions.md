## 当前核心结论

### 1. 新链热度只是底层势能，项目仍需创造自己的传播单位

Robinhood Chain 自带 RWA、Stock Token、Robinhood 用户与新链红利，但真正跑出的项目都有一个可被反复复述的单位：Pons 的 `memestocks` 和回购销毁、LONG 的“股票 × Meme”、NetNet 的 `RW-Play`、RPG 的 Summoning Rite。

Lumiterra V2 也需要一个能代表真实产品行为的传播单位，而不是只并列 Agent、Fully Onchain、GameFi 和 OHM。

### 2. 最有效的内容源头是产品事件，不是内容日历

成交量、Stock Token 配对、Treasury、游戏奖励、NFT mint、工具上线和线下持有人权益持续给项目制造新闻。内容团队的工作是选择、命名和解释事件。

没有产品事件时，增加发帖频率只会增加重复。

### 3. 短推负责记忆，长内容负责可信度

Pons、LONG、Orangu 用极短文本和视觉制造记忆；StarPlatinum、Vic TALK、RobinHub 和项目长文再解释机制、创始人、时间线和风险。二者不是替代关系。

Lumiterra 每个重要更新应同时准备一句 Hook、一个视觉证据、一段机制解释和一组可核验来源。

### 4. 排行榜和名单是强收藏内容，因为它们降低搜索成本

用户提供的 NFT 项目清单、Top Plays、Daily Recap 和必盯账号都在替用户完成发现与排序。它们高收藏的原因更可能是工具价值，而不是单一项目粉丝情绪。

Lumiterra 可以创建与自身世界或 Agent 行为相关的观察榜、策略榜、创作者榜，但需要真实数据和透明规则。

### 5. KOL 分发应按职能设计，而不是只按粉丝量采购

- 官方/关键人物提供高权重信号；
- 生态媒体提供发现和重复曝光；
- 研究型 KOL 提供机制与时间线；
- 区域内容号提供本地语言框架；
- 项目伙伴、Space 与社区提供转化和留存。

同一篇广告稿无法同时发挥这些角色的价值。

### 6. 创始人或核心成员账号是项目可信度放大器

Orangu 由 ExoticRaccoon 的行业背景与个人 quote 放大；Pons 的构建故事被研究型 KOL 组织成创始人时间线；NetNet 用署名式 Shareholder communication 建立连续人格。

对 Lumiterra 来说，核心成员应发布设计判断、原型证据和失败/迭代过程，项目账号则维护清晰的官方事实。

### 7. 社交裂变在进入产品世界后才有长期价值

RPG 把关注、互动、发帖和邀请转换成召唤机会，再连接职业选择与 boss progression。这比抽奖式关注任务更能传递产品。

Lumiterra 更适合用 Agent 决策 Preview、性格测试、策略挑战和结果卡承接推荐，而不是把点赞本身当作贡献。

### 8. 身份语言能把分散行为变成群体

`farmers`、`warriors`、`Shareholders`、`brokers`、`outlaw` 都让用户在参与前先知道“我在这里是谁”。固定 emoji、角色语言和动词增强识别。

身份必须对应真实角色或贡献，否则会快速退化为空洞口号。

### 9. 合作的真正价值是共享行为，不是 Logo

Unvault 的多链分配、collection allocation、holder reward 与 Space；StonkBrokers 的工具、股票奖励与线下 Dinner；NetNet 的游戏产出 NFT，都让合作方用户发生了可观察行为。

Lumiterra 合作应回答：对方用户进入后能做什么、得到什么产品反馈、产生什么可验证结果。

### 10. 数据是内容燃料，也是最大风险

链上项目用成交量、TVL、Treasury 和持有人不断制造社会证明。但这些指标会受价格、浅流动性、机器人、wash trading 和统计口径影响。

Lumiterra 只发布可解释的历史事实，附时间窗口与口径；不把目标、估算或经济结果写成承诺。

### 11. 高互动不等于高质量用户

Yield Fields、RPG 和 Orangu 的部分帖子具有很高的回复/转发比例。RPG 已确认存在社交任务；其他项目没有公开渠道归因数据。因此互动只能说明传播发生，不能证明自然增长、产品转化或留存。

KOL 与活动复盘必须连接到 Preview、测试、游戏与留存数据。

### 12. “制造热度”的合规边界必须提前写进执行规则

可复用的是分层发布、真实事件、公开挑战、UGC、Space、推荐追踪和伙伴社区；不可复用的是买量造假、机器人互动、未披露的利益关系、复制粘贴和虚假数字。

X 明确禁止协调虚假互动与指标膨胀。短期数字不能以账号与品牌长期信任为代价。

## Lumiterra V2 的建议起点

以下为待验证建议：

1. 选择一个 10–20 秒就能证明“Agent 真的在行动”的 Prototype 片段。
2. 做一个无需先理解经济系统的 Agent 决策 Preview。
3. 生成可分享结果卡，并让好友能挑战另一种 Agent 性格或策略。
4. 为生态媒体、研究型 KOL、游戏创作者和区域内容号分别准备材料。
5. 用测试完成率、有效邀请和 7/30 日回访评价传播，而不是只看曝光。

## 结论边界

当前没有公开资料能确定各项目的 KOL 费用、付费曝光比例、社交任务带来的真实用户数、自然/机器人互动比例或长期留存。本研究解释可观察的营销结构，不构成渠道归因模型，也不提供 token 或 NFT 投资判断。
