# RC-034 · RPG Onchain 独立营销研究

> 快照：2026-09-03 · 类型：RPG/NFT · 证据强度：中

## 1. 项目身份与母帖

[官方账号](https://x.com/RpgOnchain)宣称 355 个免费 Genesis mint 将上线 Robinhood，由 [P2](https://x.com/TheMaran/status/2095051605817393425)和 [P4](https://x.com/StarPlatinum_/status/2094831906181267598)提及。

## 2. 背景与入场

项目用 warrior、boss、summoning rite 把白名单包装为游戏内试炼，而非表单任务。

## 3. 高表现推文拆解

[Summoning Rite 帖](https://x.com/RpgOnchain/status/2092617196048416866)用“355 warriors”“not all will be chosen”“Are you worthy?”推进，快照约 5.9 万浏览、566 回复、2,091 转发、4,024 喜欢。结构是名额 → 淘汰风险 → 身份升级 → 仪式入口。

## 4. 活动、拉新与裂变

[Genesis Chests 帖](https://x.com/RpgOnchain/status/2094455803612914125)继续用打 boss/升级叙事，快照约 1.2 万浏览；免费 mint + 稀缺 355 + 资格仪式构成强裂变。

## 5. KOL 与分发路径

官方仪式帖 → 大量转发 → NFT 清单 [P2](https://x.com/TheMaran/status/2095051605817393425) → 中文清单 [P4](https://x.com/StarPlatinum_/status/2094831906181267598)。

## 6. 热度形成判断

判断：把运营动作完全写进世界观，是其最强内容能力；高转发质量仍需审计。

## 7. 对 Lumiterra V2 的启示

测试资格、邀请码和任务都可成为世界内事件，但必须连接真实可玩内容。

## 8. 未验证事项

游戏完成度、mint 规则、互动质量、代币、团队和留存待确认。
