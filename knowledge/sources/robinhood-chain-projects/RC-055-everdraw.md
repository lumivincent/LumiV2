# RC-055 · Everdraw 独立营销研究

> 快照：2026-09-03 · 类型：卡牌/RPG 任务游戏 · 证据强度：中

## 1. 项目身份与母帖

[官方账号](https://x.com/Everdraw_RPG)定位为组队、选择路径、获取奖励的 realm，由 [P4](https://x.com/StarPlatinum_/status/2094831906181267598)提及。

## 2. 背景与入场

[角色合集 thread](https://x.com/Everdraw_RPG/status/2093485627773739225)用“opening the Grimoire”开启完整说明，快照约 8.7 万浏览、230 回复、88 转发、583 喜欢；文档式内容也被包装成世界内物件。

## 3. 高表现推文拆解

[Easter Egg 警告帖](https://x.com/Everdraw_RPG/status/2093025188786974751)明确彩蛋会消失、找到可获 badge、未来可能有惊喜，快照约 2 万浏览。结构是期限风险 → 探索动作 → 确定徽章 → 未揭示未来价值。

## 4. 活动、拉新与裂变

[次日消失帖](https://x.com/Everdraw_RPG/status/2094508691651174481)再次倒计时并预告新任务；[选择 Guilds 任务](https://x.com/Everdraw_RPG/status/2095317420705476775)要求升级卡牌提高成功率，连接内容、进度和社群身份。

## 5. KOL 与分发路径

角色 thread → 限时彩蛋 → badge → 新 quest/guild → P4 清单。

## 6. 热度形成判断

判断：连续可执行任务比单次 WL 更能形成回访，且每次帖子都改变游戏状态。

## 7. 对 Lumiterra V2 的启示

这是最贴近 Lumiterra 的案例：推文应指向游戏内限时状态、可获得证明和下一任务，而非纯社交任务。

## 8. 未验证事项

实际游戏完成度、成功率、奖励、badge 用途、付费点和留存待确认。
