# RC-021 · Index 独立营销研究

> 研究快照：2026-09-03 · 类型：股票分红/RWA 协议 · 证据强度：中

## 1. 项目身份与母帖

Index 的[官方账号](https://x.com/TheIndexFi)定位为 Robinhood L2 tokenized stocks 的 stock dividend protocol，出现于 [P1](https://x.com/RobinHubHB/status/2095198531393040724)、[P5](https://x.com/RobinHubHB/status/2094953456058458575)与 [P7](https://x.com/victalk6886/status/2094923877142966648)。

## 2. 背景与入场

[品牌视频帖](https://x.com/TheIndexFi/status/2079358227335000369)只写“Assets that build your future. Only on @RobinhoodCrypto”，快照约 31 万浏览、185 回复、195 转发、1,137 喜欢，用传统投资语言连接加密用户与股票资产。

## 3. 高表现推文拆解

视频帖结构极短：未来利益 → 平台独占 → 视频，依靠成熟金融视觉完成解释。[RWA 分发里程碑帖](https://x.com/TheIndexFi/status/2094576268331127014)用“Over $1,500,000”开头和“Stocks for everyone”收尾，快照约 4.3 万浏览；金额为项目方自报。

## 4. 活动、拉新与裂变

[机制解释帖](https://x.com/TheIndexFi/status/2093980538981781685)把链上交易量转成 tokenized equity rewards，构成“生态越活跃—持有人越有故事可讲”的飞轮。实际分配需链上核验。

## 5. KOL 与分发路径

官方品牌视频 → 社区账号/建设者扩散 → 多份生态清单反复出现。三个母帖交叉提及显示较强心智占位，不等于合作背书。

## 6. 热度形成判断

判断：把复杂 RWA 价值压缩为“股票进入你的口袋”，再用累计分发数字制造证明，是其主要增长方法。

## 7. 对 Lumiterra V2 的启示

经济机制内容需要一句用户结果和可审计面板；未经验证的分发数字不能成为 Lumiterra 承诺。

## 8. 未验证事项

RWA 来源、分发金额口径、法律结构、持有人净收益、审计和用户留存待确认。
