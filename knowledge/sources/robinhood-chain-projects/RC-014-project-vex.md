# RC-014 · Project:VEX 独立营销研究

> 研究快照：2026-09-03 · 类型：资本管理 Agent · 证据强度：中

## 1. 项目身份与母帖

Project:VEX 在[官方账号](https://x.com/ProjectVEXai)使用“The agent you can trust with capital”定位，出现在 [P1](https://x.com/RobinHubHB/status/2095198531393040724)。

## 2. 背景与入场

[App 发布帖](https://x.com/ProjectVEXai/status/2075581943174103072)直接把“可信地管理资本”作为能力上限；快照约 29 万浏览、130 回复、86 转发、701 喜欢。它先卖高价值结果，再解释基础设施，是典型 Agent 项目切入法。

## 3. 高表现推文拆解

发布帖结构为：产品已到 → 一句定位 → 为什么难 → “能管钱就能做任何事”的放大结论 → 视频。强 Hook 和短论证降低理解成本。[Agentic ecosystem 帖](https://x.com/ProjectVEXai/status/2093685587542954152)以“before you even notice”制造提前上车感，快照约 1.2 万浏览，但仍是叙事，不是业绩证明。

## 4. 活动、拉新与裂变

[runner 帖](https://x.com/ProjectVEXai/status/2094100366086611207)把“发现上涨资产”升级为“由 Agent 创造 runner”，借 @pools_dot_fun 的可交易资产形成使用传播。未见可验证推荐奖励。

## 5. KOL 与分发路径

路径是 App 视频建立认知 → 与 launch/market 项目互相引用 → RobinHub 榜单收录。没有证据证明榜单收录为付费。

## 6. 热度形成判断

判断：核心是用“资本可信”这个高风险、高价值问题制造权威，再用短句持续投喂 Agentic Capital Market 叙事；转化证据弱于内容声量。

## 7. 对 Lumiterra V2 的启示

Lumiterra Agent 内容应给出“输入—决策—行动—结果”样例；口号可负责引流，但可信度要由可复查日志承担。

## 8. 未验证事项

资产托管权限、执行记录、收益、风控、Robinhood 专属集成及用户规模待确认。
