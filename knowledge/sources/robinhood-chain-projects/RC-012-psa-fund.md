# RC-012 · PSA Fund 独立营销研究

> 研究快照：2026-09-03 · 证据状态：项目处于早期上线/概念证明；Agent 收益尚不能视为已实现。

## 1. 项目身份与母帖

PSA Fund 自称构建在 Robinhood Chain、由 evolving agent 驱动、把 Pons trading revenue 分配到 RWA 的 sovereign fund，[官方账号](https://x.com/PSA_Fund)、[官网](https://www.psa.fund/)。它同时出现在 [P1](https://x.com/RobinHubHB/status/2095198531393040724) 与 [P5](https://x.com/RobinHubHB/status/2094953456058458575)。

## 2. 背景与入场

[上线帖](https://x.com/PSA_Fund/status/2094794151930011822) 先写“treasury is open”和合约，再定义 PON Sovereign Agent 能分析市场、配置资本和执行；2026-09-03 快照约 4,363 浏览。此帖证明的是项目公开上线与愿景，不证明 Agent 已经产生利润。

官网在同日快照仍出现 `PRE-LAUNCH`、`TVL $0`、`STATUS NOT YET LIVE` 和连接错误，同时展示 2/2 tax、80% treasury、20% buyback/burn 的配置，[官网](https://www.psa.fund/)。这与 X 的“live”存在阶段表述差异，必须保留为重要风险，而不能择一宣传。

## 3. 高表现推文拆解

[Agent execution loop 帖](https://x.com/PSA_Fund/status/2094835068036657398) 用 Market State → Data → Signal → Regime → Scoring → Risk → Constraints → Routing → PnL → Memory 的流程建立技术感。它是架构叙事，没有公开运行日志或审计证据。

[利润回流愿景帖](https://x.com/PSA_Fund/status/2094842602059444242) 反复使用“It analyzes / allocates / executes / adapts”，最后说 profits flow back to ecosystem and holders。开头明确用了 `Imagine when`，说明属于未来场景；二次传播时不能删掉这个条件词。

## 4. 活动、拉新与裂变

目前可见增长主要依靠 Agent/RWA 愿景和 Pons 关联，未找到独立任务或推荐规则。

## 5. KOL 与分发路径

Pons revenue 叙事 → PSA 官方架构帖 → RobinHub 榜单，付费关系未证实。

## 6. 热度形成判断

PSA 借 Pons revenue、Robinhood Agentic/RWA 叙事和终端视觉建立合法性，当前更接近概念预期而非成熟增长。

## 7. 对 Lumiterra V2 的启示

流程图能帮助解释 Agent，但必须配真实输入、决策、行动与结果记录。Lumiterra 可以展示 Agent 决策链，却不应把尚未执行的策略写成已产生回报；这正是 PSA 案例最重要的反面边界。

## 8. 未验证事项
