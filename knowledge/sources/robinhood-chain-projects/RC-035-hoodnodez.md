# RC-035 · Hoodnodez 独立营销研究

> 快照：2026-09-03 · 类型：可用型 Node NFT/游戏 · 证据强度：中

## 1. 项目身份与母帖

[官方账号](https://x.com/hoodnodez)称其为“working collectible nodez”，由 [P2](https://x.com/TheMaran/status/2095051605817393425)提及。

## 2. 背景与入场

账号仅 3 帖，把项目写成“来自死亡网络的 8,888 台机器”，用完整设定而非日常碎片进入市场。

## 3. 高表现推文拆解

[“The Dungeon is opening”帖](https://x.com/hoodnodez/status/2094192202142347605)只有一句、网址和视频，快照约 145 万浏览、8,040 回复、3,048 转发、1.4 万喜欢。[purpose 帖](https://x.com/hoodnodez/status/2094894338912182524)约 76 万浏览。表现极高，但互动来源与真实性未核验。

## 4. 活动、拉新与裂变

[Transmission 长文](https://x.com/hoodnodez/status/2095264837555322941)在 mint 前集中解释 game、角色、用途和时间，快照约 25 万浏览；先神秘预热，临门再给完整说明。

## 5. KOL 与分发路径

极简视频 → 资格入口 → mint 前长文 → NFT 榜单收录。未发现可证明的付费 KOL 清单。

## 6. 热度形成判断

判断：三帖高集中发布制造稀缺感；异常高互动必须与链上 mint 和独立受众数据交叉验证。

## 7. 对 Lumiterra V2 的启示

预热可少而精，但测试资格与功能说明不能一直隐藏；需防虚荣指标误导。

## 8. 未验证事项

互动质量、8,888 供应、工作节点功能、游戏、mint、团队和合约待确认。
