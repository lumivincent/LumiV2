# RC-017 · ClawBank 独立营销研究

> 研究快照：2026-09-03 · 类型：Agent 原生金融/公司基础设施 · 证据强度：中

## 1. 项目身份与母帖

ClawBank 的[官方账号](https://x.com/ClawBankHQ)自称“Crypto-Native Zero Human Company”，由 [P1](https://x.com/RobinHubHB/status/2095198531393040724)提及。

## 2. 背景与入场

[Policy Engine 长文](https://x.com/ClawBankHQ/status/2081743932107485389)用 spending limits、scoped keys、2FA 解释 Agent 如何安全花钱；快照约 7,963 浏览。内容从风险控制切入，和多数只讲自主性的 Agent 项目形成差异。

## 3. 高表现推文拆解

长文标题“Armor for Your Fleet of Sovereign Agents”把抽象权限管理翻译成护甲隐喻；随后落到每日 10 美元等具体限制。结构是隐喻 Hook → 风险 → 控件 → 用例，适合技术产品。[Agent-first 帖](https://x.com/ClawBankHQ/status/2094847460380127497)用“不是在 SaaS 里塞 Agent”制造对立，再列发现、开户、购买能力、运行四步。

## 4. 活动、拉新与裂变

可见增长主要靠产品教育和开发者入口，不是空投或排行榜；转化对象是 Agent builder，而非普通散户。

## 5. KOL 与分发路径

官方长文 → 开发者讨论/引用 → RobinHub 的 Agent 工具聚合。尚未找到明确付费 KOL 或 Robinhood 官方合作证明。

## 6. 热度形成判断

判断：以安全具体性换取可信度，是专业窄众增长；声量可能较小，但用户意图更强。

## 7. 对 Lumiterra V2 的启示

Agent 营销不只讲“能做什么”，也应讲权限边界、失败保护和玩家可控项，这会直接提升可信度。

## 8. 未验证事项

Robinhood 原生集成、公司法律状态、实际 Agent 数、资产量、安全审计与收入待确认。
