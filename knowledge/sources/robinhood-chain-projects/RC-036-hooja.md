# RC-036 · Hooja 独立营销研究

> 快照：2026-09-03 · 类型：Meme + NFT · 证据强度：中

## 1. 项目身份与母帖

[官方账号](https://x.com/hoojafun)以“Robinhood chain outlaw”定位，出现于 [P2](https://x.com/TheMaran/status/2095051605817393425)和 [P4](https://x.com/StarPlatinum_/status/2094831906181267598)。

## 2. 背景与入场

Hooja 已有代币社区，再把 NFT 与代币绑定，属于从 Meme 向产品/收藏品延伸。

## 3. 高表现推文拆解

[V2 migration 长文](https://x.com/hoojafun/status/2087632012571980164)明确迁移代币、同步发 NFT，并通过 Clutch Labs 的 Anvil NFT AMM 绑定两者；快照约 3.2 万浏览、50 回复、140 转发、989 喜欢。结构是重大变更 → 两资产同步 → 技术桥梁 → 后续细节。

## 4. 活动、拉新与裂变

[Space 预告帖](https://x.com/hoojafun/status/2095224710652920111)与 @unvault、@FunkariNft 共同讨论“NFTs are dead?”，以争议问题为 Space Hook。

## 5. KOL 与分发路径

代币社区 → 技术合作方 Clutch → NFT 平台 Unvault/主持人 → 两个清单重复收录。

## 6. 热度形成判断

判断：迁移事件、NFT 扩品和合作 Space 让旧社区获得新的谈资；迁移也带来合约风险。

## 7. 对 Lumiterra V2 的启示

版本升级内容应解释旧资产如何过渡、为什么升级、用户要做什么，并提供安全入口。

## 8. 未验证事项

迁移完成率、Anvil 机制、NFT mint、代币价值捕获和审计待确认。
