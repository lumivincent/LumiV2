# RC-050 · Broker APP / BAPP 独立营销研究

> 快照：2026-09-03 · 类型：NFT + Token + RWA · 证据强度：低至中

## 1. 项目身份与母帖

[官方账号](https://x.com/Bappfun)称有 1,000 个 Broker App NFTs，并直接链接 @robinhoodapp；由 [P4](https://x.com/StarPlatinum_/status/2094831906181267598)提及。账号链接不等于 Robinhood 官方合作。

## 2. 背景与入场

[V2 长文](https://x.com/Bappfun/status/2092669900200321081)标题直接写“TOKEN + NFT = Earnings system”，快照约 2.9 万浏览、1,200 喜欢；正文提到未来阶段的专属权益、早期准入和税费收入分成。

## 3. 高表现推文拆解

公式式标题把三资产关系压缩成收益结果，易传播但容易让预期先于证据。[claim 帖](https://x.com/Bappfun/status/2095211912363483168)只写“stock dividends ready”加链接，快照约 2,946 浏览，是直接召回模板。

## 4. 活动、拉新与裂变

项目声称可每小时领取 stock dividends，[提醒帖](https://x.com/Bappfun/status/2095213800630739380)持续召回；分红真实性、来源和频率需链上核验。

## 5. KOL 与分发路径

收益长文 → KOL/用户展示 → 高频 claim 提醒 → P4 清单。

## 6. 热度形成判断

判断：明确、频繁的领取动作会提高回访，但也可能只产生逐利活跃。

## 7. 对 Lumiterra V2 的启示

召回内容应指向真实游戏权益/任务，而非用未经验证的金融收益承诺驱动。

## 8. 未验证事项

股票资产、分红来源、税费、claim 合约、合作、mint、收入和审计待确认。
