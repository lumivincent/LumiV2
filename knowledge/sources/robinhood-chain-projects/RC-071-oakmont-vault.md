# RC-071 · Oakmont Vault 独立营销研究

> 快照：2026-09-03 · 类型：自生息指数金库/信贷 · 证据强度：中

## 1. 项目身份与母帖

[@OakmontVault](https://x.com/OakmontVault)定位为 self-yielding index vault with capital-efficient credit，并公开 STRIKE/RESERVE 合约；P7 将其误拼为 Okment，[原帖](https://x.com/victalk6886/status/2094923877142966648)。

## 2. 背景与入场

项目用“reverse OHM”解释复杂机制，[套利利润帖](https://x.com/OakmontVault/status/2094466738872254952)自报产生 4,000 美元并加入指数，快照约 3,859 浏览。

## 3. 高表现推文拆解

帖子结构是结果数字 → 资金去向 → 熟悉协议类比 → 抵押演化；能快速理解，但利润和抵押口径需链上核验。[指数机制帖](https://x.com/OakmontVault/status/2089930941229605153)用“nine positions / no rebalance / let winners run”建立规则清晰感。

## 4. 活动、拉新与裂变

[Simple Farmer Space](https://x.com/OakmontVault/status/2089467355474645331)快照 807 tuned in；[复盘帖](https://x.com/OakmontVault/status/2089726294259048630)把长音频转成摘要，延长内容寿命。

## 5. KOL 与分发路径

专业 KOL Space → 复盘图 → 机制/利润更新 → P7 榜单。

## 6. 热度形成判断

判断：教育型 Space 加熟悉协议类比适合复杂 DeFi，但自报收益不能代替审计。

## 7. 对 Lumiterra V2 的启示

复杂经济说明可用直播 + 图文复盘双层内容，并对所有数字给可验证面板。

## 8. 未验证事项

4,000 美元利润、抵押率、指数资产、审计、Space 关系和用户资金风险待确认。
