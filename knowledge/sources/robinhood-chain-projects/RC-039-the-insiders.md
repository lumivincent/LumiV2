## 2. 背景与入场

[机制长文](https://x.com/TheInsidersRH/status/2091612221361336368)标题直接用“NFTs + Stocks + Weekly Game + Robinhood”，快照约 2 万浏览，把四个模块组合成一句产品定义。

## 4. 活动、拉新与裂变

[Board 开放帖](https://x.com/TheInsidersRH/status/2094181788767629620)采用 one NFT, one vote，给明确首轮截止；[倒计时帖](https://x.com/TheInsidersRH/status/2095028698936398094)召回提案和投票。

## 5. KOL 与分发路径

机制长文 → 每周比赛 → 治理轮次 → 销毁里程碑 → NFT 清单。

## 6. 热度形成判断

判断：周赛和治理给 NFT 持有人持续回访理由，比一次性 reveal 更可持续。
