# Robinhood Chain KOL 与分发图谱

> 快照：2026-09-03。账号分层来自用户提供的 [P6 必盯账号帖](https://x.com/oragnes/status/2094970710984978498)并结合另外六条母帖和项目原帖复核。公开资料不能证明未披露的付费关系；“提及、关注、引用、合作、商业投放”必须分别描述。

## 1. 链方与高权重官方节点

- [@RobinhoodApp](https://x.com/RobinhoodApp)、[@RobinhoodCrypto](https://x.com/RobinhoodCrypto)：平台/链的官方发布。CASHCAT 获得的最强信号是 [RobinhoodApp 原帖](https://x.com/RobinhoodApp/status/2085358038181990461)及 [Robinhood 支持页](https://robinhood.com/us/en/support/articles/coin-availability/)，不应泛化为官方替其他项目背书。
- [@vladtenev](https://x.com/vladtenev)、[@BaijuBhatt](https://x.com/BaijuBhatt)、[@JohannKerbrat](https://x.com/JohannKerbrat)、[@fern](https://x.com/fern)、[@abhishekf96](https://x.com/abhishekf96)、[@GrantBradford](https://x.com/GrantBradford)：由 [P6](https://x.com/oragnes/status/2094970710984978498)列为团队/生态关键人物。只有能点开的本人原帖、引用或明确互动才应进入项目报告；不能把 P6 的“建议关注”写成这些人支持某项目。

运营作用：提供最高权重的链级事实、产品状态和文化信号。项目方最好的做法是创造值得官方自然引用的真实产品事件，不是反复 tag。

## 2. 早期发现与交易叙事节点

[P6](https://x.com/oragnes/status/2094970710984978498)列出的早期发现者包括 [@yeon_](https://x.com/yeon_)、[@kenjidgn](https://x.com/kenjidgn)、[@PhilOnChai](https://x.com/PhilOnChai)、[@Wolves_Techml](https://x.com/Wolves_Techml)、[@GuarEmperor](https://x.com/GuarEmperor)、[@KookCapitalLLC](https://x.com/KookCapitalLLC)和 [@Cyril_Cryptt](https://x.com/Cyril_Cryptt)。P6 对“最早、某市值阶段喊过”的描述尚未逐条回溯到原帖时间戳和链上价格，因此本研究只把他们列为待监测账号，不确认早期收益归因。

运营作用：发现 ticker、讲潜在上涨和快速制造第一批交易讨论。对 Lumiterra 这类长期游戏，他们只适合传递明确的原型事件或生态新闻，不应主导产品叙事。

## 3. 大型加密 KOL 与 Meme 放大节点

[P6](https://x.com/oragnes/status/2094970710984978498)列出 [@cypherpunkgod](https://x.com/cypherpunkgod)、[@theunipcs](https://x.com/theunipcs)、[@CryptoKaleo](https://x.com/CryptoKaleo)、[@blknoiz06](https://x.com/blknoiz06)、[@Mrbankstips](https://x.com/Mrbankstips)、[@eliz883](https://x.com/eliz883)、[@Arnold__AI](https://x.com/Arnold__AI)。本轮未找到足以统一证明其合作性质的公开材料；如果后续使用其帖子，必须保存具体原帖、时间、披露语句和当时项目阶段，而不能只保存账号名。

运营作用：把小圈层话题推向更大 CT 受众。其曝光可能带来价格/关注跳升，也可能带来低留存投机用户；评估应连接到产品激活和回访。

## 4. 生态聚合、研究和本地化节点

- [RobinHub Daily Recap](https://x.com/RobinHubHB/status/2095198531393040724)与 [Top Plays](https://x.com/RobinHubHB/status/2094953456058458575)：负责把碎片化更新做成每日/每周发现入口。RobinHub 账号自述非 Robinhood 官方，[主页](https://x.com/RobinHubHB)。
- [Maran NFT 清单](https://x.com/TheMaran/status/2095051605817393425)：把 14 个 NFT/Game 账号压成一句话定位，适合收藏和项目发现。
- [StarPlatinum NFT/Game 清单](https://x.com/StarPlatinum_/status/2094831906181267598)：按 Gaming/NFT 归类，承担项目筛选和中文/双语受众发现。
- [Vic TALK 长文/视频](https://x.com/victalk6886/status/2094923877142966648)：把项目归为 Meme、币股配对、DeFi 等主线，负责机制解释和风险提醒。
- [PANews Meme 日报](https://x.com/PANewsCN/status/2094964412839076066)：将英文链上热点重组为中文榜单；交易量仍需回到数据源。
- [P6 必盯账号图](https://x.com/oragnes/status/2094970710984978498)：把官方人物、早期发现者、大 KOL 和工具号装进一张监测地图。

运营作用：聚合号提供重复曝光，研究号提供“为什么”，区域号提供本地语言和排序。项目应分别提供事实卡、机制材料和本地参与方式，不应让所有人复制同一广告文案。

## 6. 可观察的分发链

```text
链方事实/关键人物信号
→ 项目官方把产品事件写成一个可转述 Hook
→ 合作平台、创始人和持有人社群交叉引用
→ 聚合号进入日报/榜单，降低发现成本
→ 研究型 KOL 写机制、背景和时间线
→ 区域账号本地化为主线、清单和参与方式
→ UGC、任务、推荐、Space 或线下活动承接行动
```

这条链在 CASHCAT 中可看到“RobinhoodApp 原帖 → 项目致谢/视频 → 媒体/KOL 榜单”，[RC-045](robinhood-chain-projects/RC-045-cashcat.md)；在 Robillio/Mana Wizards 中可看到“项目机制 → 多社区 holder-gating → 名单快速领完 → KOL 清单”，[RC-048](robinhood-chain-projects/RC-048-robillio.md)、[RC-049](robinhood-chain-projects/RC-049-mana-wizards.md)；在 Nibblins 中则是“售罄 → 透明退款 → Reveal → 清单收录”，[RC-054](robinhood-chain-projects/RC-054-nibblins.md)。

## 7. 后续记录 KOL 原帖的统一字段

每次新增 KOL 证据必须保存：原帖链接、发布时间、项目阶段、账号角色、是否披露利益关系、Hook、正文结构、素材、互动快照、导向入口、可验证产品行为，以及 7/30 日后仍能观察到的结果。只有账号名或截图，不足以形成合作结论。

## 8. Lumiterra V2 的分发建议

以下是运营建议：链/生态官方只接收确认事实；聚合号接收更新卡和素材；研究型 KOL 接收机制、时间线、风险和试玩；游戏创作者接收可玩片段/角色；区域账号接收本地化参与路径；社区创作者按真实试玩、攻略、Bug 与有效邀请获得身份。任何付费、allocation 或利益交换需披露，且用激活与留存而非曝光评价。
