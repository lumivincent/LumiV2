# Lumiterra V2 产品需求文档

> 本文档只记录产品与业务需求。数值、公式和成长曲线统一参考 [`numeric-core.md`](./numeric-core.md)。

## 1. 产品概述

Lumiterra V2 是运行在 Monad 上、由 Agent 主导的 Fully Onchain 养成放置类游戏。

Agent 通过战斗、采集和种田获得物品与固定财富值，再通过合成、交易、回收和 Token 奖池参与经济循环。拥有 Agent 后，玩家使用 `Energy` 理解生产、Agent 运行、模型调用和链上操作成本；没有 Agent 时，宠物手动操作的链上 Gas 由玩家钱包直接支付。

## 2. 角色与控制

游戏只有一种角色模型。Agent 和人类宠物是两种控制入口，不是两套角色或成长系统。所有账户默认没有 Agent，玩家可以先选择宠物形象免费进入游戏，Agent 需要后续购买。

| 控制方 | 功能 |
|---|---|
| Agent | 购买后自动控制角色执行移动、战斗、采集、种田、合成和经济行为 |
| 人类 | 直接控制宠物；拥有 Agent 后，还可以管理 Agent 的 Prompt、Context、Behavior Codes、启停、预算和资产 |

### 2.1 Agent 宠物

- 玩家首次进入时选择自己的宠物形象；形象只影响外观，不改变属性或玩法能力。
- 创建宠物和领取初始装备不要求游戏内付费或 Energy 充值，但玩家钱包需要自行承担链上 Gas。
- 宠物可以执行 Agent 能执行的游戏行为，并遵守相同的位置、能力、资源和链上规则。
- 账户没有 Agent 时，宠物使用最低属性；拥有 Agent 后，宠物属性取最低属性与所属账户最强 Agent 的 33% 属性中的较高值，计算规则见数值文档。
- 宠物最低属性应能配合初始装备完成普通 Lv1 战斗、采集和种田，但不保证能够完成精英、Boss 或其他高难度对象。
- 宠物拥有容量为 2 的未激活产出背包；背包剩余容量不足时，不能执行会获得新物品的行为。
- 玩家首次创建宠物时获得 Lv1 初始武器、斧头、镐子、镰刀、锄头和水壶。
- 初始装备与账户绑定，固定财富值为 0，不能交易、借贷、回收、投入奖池或作为装备升级材料。
- 初始装备保存在装备栏，不占用宠物的未激活产出背包容量。

### 2.2 Agent 配置

玩家购买的每个 Agent 包含以下可配置内容：

- System Prompt
- Context
- Behavior Codes
- 性格参数

性格使用五个 `0–100` 参数：风险偏好、目标专注、探索倾向、合作倾向和资源谨慎。参数只影响决策权重和 Prompt，不影响链上数值。

## 3. 核心循环与成长

```text
Agent 自动执行 / 人类通过宠物手动执行
→ 战斗、采集或种田
→ 没有 Agent：产出进入未激活背包
→ 拥有 Agent：支付生产 Energy 后激活产出
→ 符合资格时结算固定财富值和 Agent 成长进度
→ 合成、交易、借贷、回收或投入 Token 奖池
```

### 3.1 Agent 成长

- Agent 不设置用于穿戴、生产或资格判断的角色等级；每个 Agent 只保存一条 Lv1–9 成长阶段与有效成长掉落进度，不按职业拆分。
- 战斗、采集和种田产生的合格有效成长掉落直接累加到同一条进度，成长判定不读取掉落所属职业；当前阶段累计获得 2,000 件后进入下一阶段。
- 每件有效成长掉落计为 1 点进度；阶段提升不消耗物品，也不额外消耗 Energy、财富值或 Token。
- Agent 从 Lv1 成长至 Lv9 的目标有效生产时间保持为 720 小时。
- 每阶段所需数量固定为 2,000 件；平均获取间隔随成长阶段从 1 分钟逐步增加至 5 分钟。
- 三种玩法通过对象强度、行动时间和基础掉落数量校准获取速度；同成长阶段、典型装备条件下的有效成长掉落速度差距应控制在 10% 以内。
- 成长阶段只提升 Agent 的基础 HP、移动速度和背包容量，不限制装备，也不直接进入伤害或财富转化公式。
- Lv1–Lv9 分别映射到基础 HP `1×–5×`、移动速度 `1×–2.5×`、背包容量 `10–1,000`；完整曲线见数值文档。

<details>
<summary>有效成长掉落判定</summary>

- 必须由该 Agent 或其宠物通过战斗、采集或种田实际生产获得，物品等级必须等于 Agent 当前成长阶段；物品职业不参与成长判定。
- 只有支付生产 Energy 并完成激活的基础掉落计入；稀有掉落和额外奖励不计入。
- 产出生成时账户必须已经拥有 Agent；购买 Agent 前生成的未激活产出，之后即使激活也不补发成长进度。
- Marketplace 购买、P2P 转入、合成和系统赠送的物品不计入。
- 多人结算只计算最终实际分配给该参与者的物品。
- 物品计入后可以交易、合成或消耗，不会扣减已经获得的进度。
- 进入下一成长阶段后进度归零；超过 2,000 件的部分不结转。

</details>

### 3.2 装备

- 每个职业有对应装备和工具，装备提供该职业的攻击、防御和暴击属性。
- Agent 可以穿戴任意等级的装备和工具，成长阶段不作为穿戴门槛。
- 装备可以自由混搭，不要求完整职业套装。
- Agent 的基础 HP、移动速度和背包容量由成长阶段决定；装备不能增加 HP。
- 成长阶段在生产结算完成后更新；最大 HP 随阶段提高，当前 HP 不因阶段提升而恢复。
- 背包按物品数量与重量计算已用容量；所有物品的默认单件重量为 1。
- 只有物品总重量不超过背包容量时才能携带或接收；已穿戴并存放在装备栏的物品不占背包容量。
- 各职业攻击、防御和暴击率由固定职业基础数值与实际装备属性相加得到。
- 装备通过提高行动效率和财富转化效率产生价值，具体公式见数值文档。
- 绑定的 Lv1 初始装备只提供新手生产资格和对应的 Lv1 有效生产等级，不参与装备经济循环。

## 4. 三职业统一结算机制

战斗、采集和种田共用同一套 HP、回合、伤害、成功与失败规则，只替换职业属性和操作对象。

### 4.1 通用属性

| 属性 | 战斗 | 采集 | 种田 |
|---|---|---|---|
| 共享生命值 | `Health` | `Health` | `Health` |
| 攻击 | `CombatAttack` | `GatherAttack` | `FarmAttack` |
| 防御 | `CombatDefense` | `GatherDefense` | `FarmDefense` |
| 暴击率 | `CombatCriticalChance` | `GatherCriticalChance` | `FarmCriticalChance` |

怪物、资源对象和作物也使用 `Health`、当前职业攻击、防御和暴击率。

### 4.2 回合流程

```text
角色攻击对象
→ 对象 HP 归零：成功结算
→ 对象未归零：对象立即反击
→ 角色 HP 归零：失败结算
→ 双方存活：进入下一回合
```

- 一场结算只操作一个对象，同一角色不能同时发起多场结算。
- 战斗允许玩家或 Agent 在回合间选择动作。
- 采集和种田没有选择等待时间，但仍按顺序执行攻击与反击。
- 一场结算中可以使用符合职业规则的道具。
- 普通伤害倍率固定为 100%；触发暴击后，伤害倍率在 100%–200% 内随机取值。
- 暴击和多人稀有掉落共用协议随机数来源，客户端不能提交随机结果。
- 伤害、暴击和回合公式见数值文档。

### 4.3 成功、失败与超时

| 结果 | 规则 |
|---|---|
| 成功 | 对象 HP 归零；扣除生产 Energy，结算掉落、固定财富值和 Agent 成长进度 |
| 失败 | 角色 HP 归零且对象仍存活；不扣除生产 Energy，不产生掉落，角色原地复活 |
| 超时 | 不产生掉落或生产结算；角色保留剩余 HP，对象按职业规则重置 |

超时后的对象状态：

- 战斗：退出战斗，怪物恢复初始状态。
- 采集：资源对象恢复 100% HP。
- 种田：农田对象恢复初始 HP。

- 战斗连续 60 秒无操作时超时。
- 采集和种田达到 50 回合时超时，不依赖客户端时间。

行为过程中已经发生的 Agent 运行、模型调用和链上执行成本不因失败或超时退还。

### 4.4 多人参与

- 战斗、采集和种田都允许其他角色查看并动态加入进行中的结算。
- 所有参与者使用对应职业属性，并共用相同的回合、有效伤害和掉落结算规则。
- 协议串行确认每次行动，避免同一对象被重复结算。
- 对象死亡时，只计算不超过其剩余 HP 的有效伤害。
- 可拆分掉落按有效伤害占比分配。
- 不可拆分稀有掉落在有效伤害占比不低于 5% 的角色中，按有效伤害占比加权随机分配。

### 4.5 HP 恢复

- 三职业行为都可能消耗角色 HP。
- 角色可以返回主城免费恢复全部 HP。
- 角色可以使用药品主动恢复 HP。

## 5. 玩法模块

### 5.1 战斗

- 采用回合制战斗，普通、精英和 Boss 共用统一结算机制。
- 角色和宠物都可以参与战斗。
- 战斗可以配置少量技能；技能只调整当前回合的攻击、防御或暴击率，不创建第二套伤害模型。

### 5.2 采集

- 采集是单点对象操作，不提供范围采集技能。
- 树木要求斧头，矿物要求镐子，植物类资源要求镰刀；角色装备目标要求的采集工具后攻击资源对象。
- 每次攻击后，资源对象立即使用采集职业属性反击。
- 资源对象 HP 归零后结算采集掉落。

### 5.3 种田

```text
选择农田对象 → 回合生产 → 对象 HP 归零 → 立即结算掉落
```

- 种田不包含锄地、待浇水、成长、成熟或等待收获等中间状态。
- 每种农田对象配置锄头或水壶作为所需工具，两种工具不构成连续阶段；角色装备目标要求的工具后攻击农田对象。
- 每次攻击后，农田对象立即使用种田职业属性反击。
- 农田对象 HP 归零后立即结算种田掉落并重置。

### 5.4 合成

- 每个职业、每个等级固定有三种不同的基础素材；三种素材各 1 件合成 1 份同职业、同等级精华。
- 每件职业装备都依赖另外两个职业的同等级精华各 1 份，不设置 Lv1 特例。

| 目标产物 | 固定输入 |
|---|---|
| 战斗精华 | 同等级三种不同战斗素材各 1 件 |
| 采集精华 | 同等级三种不同采集素材各 1 件 |
| 种田精华 | 同等级三种不同种田素材各 1 件 |
| 战斗装备 | 同等级采集精华 1 份 + 种田精华 1 份 |
| 采集装备 | 同等级战斗精华 1 份 + 种田精华 1 份 |
| 种田装备 | 同等级战斗精华 1 份 + 采集精华 1 份 |

- Lv1 装备直接使用两种精华合成；Lv2 及以上装备还必须投入同职业、同槽位的上一等级装备。
- 合成成功后，材料和用于升级的旧装备在同一笔结算中销毁，产出 1 件目标物品。
- 合成必须在工作台允许的交互距离内执行。
- V1 使用固定配方和 100% 成功率；执行合成不额外消耗 Energy。
- 合成不增加 Agent 成长进度；合成产物的固定财富值遵守数值文档中的财富守恒公式。

## 6. 产出与 Energy

### 6.1 生产结算

- 生产 Energy 只在实际掉落物完成激活时扣除；未激活产出生成时不扣除。
- 只有已激活物品才结算固定财富值和 Agent 成长进度。
- 空产出、失败和超时不扣除生产 Energy，也不产生固定财富值或 Agent 成长进度。
- 物品、掉落率、Energy 成本和财富值统一参考数值文档。

### 6.2 待激活产出

- 账户没有 Agent 时，宠物产出默认进入未激活背包，不扣除生产 Energy，也不获得固定财富值或成长进度。
- 账户拥有 Agent 但生产 Energy 不足时，产出同样进入未激活状态。
- 待激活记录保存物品、数量、Energy 欠额、所属职业和原始行动信息。
- 待激活物品使用单独背包 Tab，可以丢弃，但不能交易、合成或参与其他经济行为。
- 宠物的未激活背包容量固定为 2；所有物品默认单件重量为 1，结算新增物品前必须验证剩余容量。
- 购买 Agent 后，玩家可以支付生产 Energy 激活购买前获得的物品并结算固定财富值，但这些历史物品不补发 Agent 成长进度。
- 购买 Agent 后产生的未激活物品，在支付生产 Energy 激活时正常结算固定财富值和 Agent 成长进度。

### 6.3 运行 Energy

- 账户没有 Agent 时不显示 Energy 充值入口；宠物手动操作产生的链上 Gas 由玩家钱包直接支付，协议不提供 Gas 补贴。
- 购买 Agent 后开放 Energy 购买与管理入口；Agent 自动操作使用不可透支的预付运行 Energy 池。
- Agent 的 Energy 余额不足时，在下一收费点或安全行动边界暂停。
- Agent 模式只展示 Energy 消耗、余额、预算和预计续航；宠物手动签名时展示钱包 Gas 需求和余额不足提示。
- `1 Energy = 1 MON`，Energy 由官方统一销售，不能在 Marketplace 中交易。

### 6.4 主城仓库

- 主城提供仓库，仓库容量无限。
- 仓库归属人类账户；宠物是该账户的人类控制入口，同一账户下的宠物和所有 Agent 共享仓库物品。
- 查看仓库清单可以远程进行；存入和取出必须由宠物或 Agent 到达主城仓库的交互距离内完成。
- 仓库物品不能跨地点直接用于生产、合成或穿戴；使用前必须先取出并由执行角色携带。
- 存取必须原子结算并校验可用数量与角色背包剩余容量，避免同一物品被多个 Agent 重复使用。
- 未激活产出不能存入仓库；完成激活后才能作为普通物品存入。

## 7. 经济模块

### 7.1 Token 奖池

- Agent 投入物品后不能撤回。
- 投入物品的固定财富值决定该 Agent 在本期奖池中的奖励权重。
- 奖池结束后按奖励权重分配 Token。

### 7.2 装备回收

- 只有配置表标记为可回收的装备可以回收。
- 回收报价只读取装备固定财富值，不读取市场价格或历史投入。
- Slow Redeem 的初始模拟值为 7 天等待期和 5% 费用。
- Fast Redeem 的初始模拟值为 10% 费用；每日额度按协议储备的一定比例动态计算。
- Fast Redeem 当日额度不足时进入等待队列，不自动切换为 Slow Redeem。

### 7.3 单件装备 P2P 借贷

- 一件装备同时只能担保一笔贷款。
- 成交后装备进入托管；借款人可以继续使用，但不能交易、转移、回收、投池或再次抵押。
- Lender 设置本金、最高 LTV、APR 和期限，成交后不能单方面修改。
- 利息从本金发放后按时间累计，提前还款不收额外费用。
- 宽限期结束后可以清算，抵押装备归 Lender 所有。
- 协议只对实际支付或回收的利息收费。

### 7.4 Marketplace、P2P 与位置

- 资金操作可以远程发起。
- Marketplace 支持远程买入；物品保存在 Marketplace，角色到达后才能 Claim。
- 卖出成交后立即获得 MON。
- P2P 交易要求双方处于允许距离内，并进行原子结算。
- 物品不能跨地点瞬移；角色必须携带生产和合成所需物品，Agent 之间通过主城共享仓库存取物品。
- 背包、仓库、资源对象、工作台、Marketplace、P2P 和回收都需要验证位置或交互距离。
